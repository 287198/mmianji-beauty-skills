# 程序化 SVG 与主题图标重绘规范

## 核心视觉法则

1. **强主题化、可辨识的图标重绘**：
   * 顶部栏、工具栏、底栏导航与发送键等需要重绘 SVG 时，必须深入提取当前主题的核心意象、造型语言和细节符号，融入轮廓、边框转角、点缀和线条气质，做到一眼能辨识功能，也一眼能看出属于这套主题。
   * **禁止画成与原生默认图标几乎无差的通用线性图标**，只换色或加一两个无关装饰也不能代替主题化设计。依据主题与创作者要求选择线条、填色和装饰的轻重，不为风格牺牲功能可辨识度。
   * 可使用统一的 `viewBox="0 0 24 24"`、一致的线宽和圆角端点作为工程起点，再根据主题调整；例如冬日主题：朋友圈→雪花水晶球、红包→带齿孔票根、AI 助手→六角冰晶、发送键→带雪风尾迹的纸飞机。
   * 注入方式：在按钮内插入 `.wf-ico-wrap` 包裹新 SVG，配合 CSS 隐藏原生 `> svg`，并在 `deactivate` 时彻底移除 `.wf-ico-wrap` 与 `.wf-iconized` 类名。
2. **程序化细线制图装饰**：
   * 用数学函数生成高精度矢量装饰（如啮合齿轮、黄金矩形与螺线、137.5° 黄金角叶序点阵、中国斗拱/帕特农建筑立面、数学公式环），比位图更清晰且体积极小。
   * 线稿透明度保持在 `0.09`–`0.45` 之间，作为背景纹理退后，绝不抢夺聊天气泡的阅读焦点。

## 内置示范模板

* `templates/icon-redraw-map.js` — 24px 细线主题图标重绘集 + 完整宿主选择器映射表（`ICON_TARGETS`）。
* `templates/procedural-gears-and-blueprint.js` — 精确齿对槽啮合齿轮生成器（`gearPath` / `meshRotation`）+ 黄金螺线与叶序点阵生成器。
* `templates/lace-border.css` — 原版 SVG 九宫格 `border-image` 蕾丝按钮/容器边框，内含描边、圆点及阴影改色说明；`templates/lace-border-source.svg` 为便于直接改色的可读原图。
* `templates/lace-units.svg` — 原版浅色与深色蕾丝单元及平铺用法，可分别调整底线、主体、高光与圆点颜色。
